This entry is a retrospective summary. It does not invent a Git commit or an implementation timestamp.

## Reason

Record Phase 3.4 soil and agricultural-analytics work that remains uncommitted.

## Previous behavior

Weather analytics existed without an ERA5-Land volumetric soil-water product or Soil Analysis page. SoilGrids REST was not an operational source.

## New behavior

ERA5-Land daily layer means, 0–100 cm root-zone profile mean, wetness proxies, dual-axis rainfall/soil chart, and Soil Analysis UI. Values are modeled reanalysis, not in-situ moisture. SoilGrids remains paused (`BUG-0010`). Plant-available water is not computed.

## Modified files

Representative sources still present:

- `ml/preprocessing/soil.py`
- `ml/preprocessing/wetness.py`
- `frontend/src/pages/SoilAnalysisPage.tsx`
- `docs/features/soil/era5_land_volumetric_moisture.md`
- `docs/features/soil/moisture_profile_visualization.md`

This retrospective does not modify soil downloaders, soil YAML, raw NetCDF, manifests, or processed soil files.

## Scientific impact

Modeled θ in m³/m³. Missing days stay null. Root-zone formula `0.07θ1+0.21θ2+0.72θ3`.

## Backward-compatibility impact

New soil and wetness products. Weather download contract unchanged.

## Tests

Documented under the listed feature records. This retrospective does not re-run soil ingestion or CDS downloads.
