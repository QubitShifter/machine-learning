## CHG-0008 — Leakage-safe agricultural ML research dataset

**Timestamp:** `2026-10-22T17:13:30Z`
**Phase:** Phase 4.0
**Type:** feature
**Status:** Verified

## Reason

The project needed a scientifically traceable historical research dataset before any forecasting model is trained: explicit issue-time cutoffs, leakage-safe weather and soil features, 1/3/7-day modeled soil-moisture targets, chronological splits, and automated temporal audits.

## Previous behavior

Daily weather, soil and wetness tables existed, as did Sentinel-2 scene quality and satellite–weather windows `D−N…D−1`. Forecast issue/valid-time contracts existed without a built sample table. There was no beginning-of-day ML feature table, no horizon-aware splits, and no research-dataset leakage audit. `suitable_for_modeling` remained false.

## New behavior

Versioned dataset `plovdiv_agricultural_ml_2023_2025` (pipeline 4.0.0) is built from local archives only:

- Issue time \(t_D\) = 00:00 UTC; last observation \(D-1\); mode `research_reanalysis`; `operational_availability_verified=false`.
- `features_daily.csv`: 1096 issue days, complete-window soil/weather history, API evaluated at \(D-1\), optional quality-gated satellite recency.
- `targets.csv`: 16440 rows (five soil variables × horizons 1, 3, 7); 55 end-of-archive targets remain null with `future_target_outside_dataset_period`; `target_source_kind=modeled_reanalysis`.
- Chronological 2023/2024/2025 holdout with 110 horizon-aware purged label rows.
- Leakage audit passed (7 critical checks).
- Readiness: modeled research `limited`; operational and ground-truth `not_ready`; `suitable_for_modeling` unchanged false.
- Baselines and metrics specified and fixture-tested; no model fitted.
- Minimal Data Quality summary labeled **Research dataset — no trained model yet.**

## Scientific impact

Issue-time features never include day \(D\) or later. Moisture-change targets use \(\theta_{D-1}\), not \(\theta_D\). ERA5-Land labels remain modeled reanalysis, not ground truth. Satellite NDVI is not invented on unobserved days. Random splits are not used. Source weather, soil and satellite archives were not rewritten. No agricultural skill is reported.

## Backward-compatibility impact

New processed outputs under `data/processed/ml/` (gitignored). Existing `daily_weather.csv`, `daily_soil.csv`, satellite quality reports and `suitable_for_modeling` are unchanged. New API `GET /api/v1/ml/research-dataset` is additive. Data Quality gains one summary card.
