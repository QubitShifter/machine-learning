## CHG-0002 — Change-history infrastructure

**Timestamp:** `2026-10-22T13:53:14Z`
**Phase:** 3.5 UI Refinement
**Type:** documentation
**Status:** Verified

## Reason

The project needed a permanent, timestamped development history that is not overwritten, with validation of IDs, timestamps, required sections, and feature/bug references.

## Previous behavior

Feature docs and bug records existed. There was no `docs/change_history.md` and no change-ID validator.

## New behavior

Markdown-first change records under `docs/changes/CHG-*.md`, an index table in `docs/change_history.md`, and `python -m scripts.change_log validate`. Retrospective Phase 3.3–3.5 entries use `timestamp: unknown` and `retrospective: true`.
