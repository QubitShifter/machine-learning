## CHG-0001 — Satellite Explorer sticky map

**Timestamp:** `2026-10-22T13:53:13Z`
**Phase:** 3.5 UI Refinement
**Type:** UI enhancement
**Status:** Verified

## Reason

The Pixel Inspector sat below Scene Information and SCL Classes, forcing users to scroll until the satellite map disappeared.

## Previous behavior

The georeferenced map used a 36 rem card. Scene Information, SCL Classes, and Pixel Inspector stacked in a sidebar and shared page scroll with the map and Historical NDVI.

## New behavior

Desktop CSS Grid workspace: map ~75–80% width, inspector `minmax(17.5rem, 21.25rem)`. Map and inspector share `clamp(22.5rem, calc(100dvh - 14.5rem), 47.5rem)`. The inspector scrolls independently. Pixel Inspector is first and expands after a click. Scene Information is collapsed by default with date, scene ID, quality, and calibration in the summary. Classification legend stays expanded by default. Hide inspector is optional. Medium screens use a narrower inspector; below 1023 px the layout is map-first stacked. A click scrolls only the inspector, does not call `window.scrollTo`, and does not fly the map. Scene changes clear the selected pixel. Page-level sticky was not used because `AppShell` `main` has `overflow-x-hidden`.
