**Timestamp:** unknown (historical implementation time was not captured on a runtime clock)

This entry is a retrospective summary of the scientific Explorer work that preceded the layout-only `CHG-0001`. It does not invent a Git commit or an implementation timestamp.

## Reason

Record histograms Auto Zoom, SCL map overlay, georeferenced pixel inspect, and multi-AOI draft geometry before the UI-refinement layout change.

## Previous behavior

Explorer showed RGB/NDVI overlays and a historical NDVI chart without server-side scene histograms, SCL overlay mode, or GeoTIFF pixel inspection. AOI geometry was the operational Plovdiv box only.

## New behavior

Scene NDVI/RGB/SCL histograms with P99 Auto Zoom; SCL overlay nearest-neighbour to the 10 m grid; `GET .../map/pixel` reads processed rasters; AOI registry plus draft geometries that do not start downloads. Histogram and overlay calculations were not changed by `CHG-0001`.
