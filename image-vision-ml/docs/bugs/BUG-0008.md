## Description

Expected: weather time series are always written as CSV. Parquet is optional.

Actual: `_write_parquet` returns False when pandas cannot find a parquet engine. That skip is intentional.

## Environment

`pyproject.toml` does not list `pyarrow` or `fastparquet` as required dependencies.

## Reproduction

`test_weather_chart_uses_dates_and_csv_does_not_need_parquet`.

## Evidence

```python
frame.to_parquet(path, index=False)
```
is wrapped in try/except and logs `Parquet export skipped`.

## Root-cause analysis

Environment/optional-dependency limitation, not a scientific defect.

## Resolution

No required-dependency change in this task. CSV remains authoritative.

## Mathematical or scientific impact

None. Daily millimetre and Celsius values live in CSV/JSON regardless of Parquet.

## Validation

Existing weather tests cover CSV without Parquet.
