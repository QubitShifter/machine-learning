## Description

Expected: a clicked satellite pixel can be compared with its inspector results while the georeferenced map remains visible.

Actual: the map occupied a 36 rem card and Pixel Inspector sat below Scene Information and SCL Classes. Scrolling the page to the inspector moved the map out of view.

## Environment

Satellite Explorer at `/satellite`, desktop-width layout, overlay-ready scene, MapLibre inspect click.

## Reproduction

1. Open Satellite Explorer with an overlay-ready scene.
2. Click a location on the georeferenced overlay.
3. Scroll to Pixel Inspector.
4. The map is no longer in the viewport.

## Evidence

Pre-fix `SatelliteExplorerPage` used `grid xl:grid-cols-[minmax(0,1fr)_20rem]` with `h-[36rem]` map and Pixel Inspector last in the sidebar.

## Root-cause analysis

The scientific panels and the map shared the page scroll. `AppShell` `main` uses `overflow-x-hidden`, so a page-level sticky map would also be fragile and could overlap Historical NDVI. The defect is layout, not raster sampling.

## Resolution

Bounded CSS Grid workspace (`.satellite-workspace`) with a map panel and an independently scrolling `.satellite-inspector-panel` of the same visual height. Pixel Inspector is first. Scene Information is collapsed by default with quality/calibration still in the summary. Classification legend stays expanded by default. Hide inspector is optional. Selected-pixel MapLibre marker does not fly the camera.

## Mathematical or scientific impact

None. NDVI, reflectance, SCL sampling, quality thresholds, histograms, soil, and weather pipelines were not modified.
