## Description

Expected: optional static soil properties could be imported from an official SoilGrids access route.

Actual: SoilGrids REST is paused. No properties were downloaded. The project adapter returns `not_available` without network calls.

## Environment

Phase 3.4 inspection of https://isric.org/explore/soilgrids/ and the published REST pause notice. No live SoilGrids download was attempted.

## Reproduction

`python -c "from ml.ingestion.soilgrids import import_soilgrids_properties; print(import_soilgrids_properties()['status'])"` prints `not_available`.

## Evidence

Source registry record `isric_soilgrids` has `integration_status: paused`. Adapter tests assert empty records and `network_executed is False`.

## Root-cause analysis

An unavailable external API is not a project-code defect. Pedotransfer field capacity and wilting point are also not fabricated.

## Resolution

- Record the source as paused in the registry.
- Ship `soilgrids_availability()` as a contract, not a successful import.
- Leave `plant_available_water_fraction` null.

## Mathematical or scientific impact

Plant-available water R is not computed. Modeled ERA5-Land θ remains unlabeled as ground truth.

## Validation

`test_soilgrids_does_not_fabricate_properties` and `test_source_registry_distinguishes_implemented_and_planned`.
