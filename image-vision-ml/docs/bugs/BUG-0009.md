## Description

Expected: audit provenance contains STAC hrefs when they are stored on the scene record; otherwise fields stay empty.

Actual: some audit rows showed empty hrefs. For `S2B_35TLG_20250119_0_L2A` the raw manifest **does** contain Earth Search COG hrefs. Empty audit hrefs occur when `audit_scene_calibration` is given a record without `assets`, not because the project should invent URLs.

## Environment

Earth Search item IDs match scene IDs. Manifest assets are HTTPS COG links.

## Reproduction

Call `audit_scene_calibration` with `record={}` → `stac_asset_hrefs_complete` is false and evidence lists `stac_asset_hrefs_unavailable:blue,green,red,nir,scl`.

## Evidence

Manifest excerpt for the January scene includes blue/green/red/nir/scl hrefs under `data/raw/satellite/plovdiv_2023_2025/manifest.json`.

## Root-cause analysis

Not manufacturing missing provenance is correct. Empty audit hrefs on this dataset were a key-name mismatch: the raw manifest stores COG links as `source_urls`, while the audit initially read only `assets`.

## Resolution

- Copy `assets` or `source_urls` from the scene record.
- Keep `stac_asset_hrefs_complete` and `stac_asset_hrefs_unavailable:*` when neither mapping has hrefs.
- Do not invent URLs, collections, or processing baselines.

## Mathematical or scientific impact

None. Reflectance math unchanged.

## Validation

`test_source_urls_are_copied_and_not_invented` passed. After `validate`, January audit `stac_asset_hrefs_complete` is true and red href is the stored Earth Search COG URL. Records without `assets` or `source_urls` remain incomplete without invented links. Independently verified at `2026-10-22T07:45:25Z`.
